# 贯穿式受众与真实性复核

## 目的

复核从意图确定开始，持续介入文案、图片提示词、成图和排版，不等到最后才找错。它同时回答三件事：

1. 目标读者是否愿意看、看得懂并知道下一步；
2. 内容是否忠于来源与用户意图；
3. 训练人物、动作和器械是否真实可执行。

这是内部 advisory 判断，不是用户研究。不要把模拟感受写成真实反馈、账号数据或效果预测。

## 读者站位

只使用 brief 中已有的目标读者和处境，不补姓名、经历、结果或引号内的假想评价。按小红书标题、逐页内容与发布正文完整通读：

- 第一感受：标题和开头是清楚、可信、被理解，还是夸张、焦虑或说教；
- 理解成本：核心判断能否自然复述，术语、数字和页面顺序是否造成停顿；
- 相关性：读者能否看见自己的场景，海外或特殊人群证据是否被直接套用；
- 信任风险：标题是否超过正文，建议是否扩大为因果、处方或保证；
- 行动阻力：动作是否具体、低门槛、可由读者控制；
- 情绪余味：读完更清楚，还是多了一条身材、体重或训练及格线；
- 人物认同：是否自然传达舒服自洽、健康力量和坦荡进取，而不是白瘦幼、年龄焦虑或迎合性凝视。

## 五个复核节点

### 1. 意图与证据

- 用户的主题、平台、模板和交付是否被检索结果悄悄替换；
- 核心主张是否有对应来源或明确标作编辑建议；
- 研究、指南、专业解释、社区语言和品牌事实是否分开；
- 未知指标、人物经历、效果和版权是否保持未知。

### 2. 平台文案

- 标题、逐页教学和发布正文是否各自承担任务，而不是重复同一句；
- 标题、封面、开头和结尾是否重复；
- 是否出现机械排比、成套反转、汇报路标、假口语和空洞总结；
- 小红书是否给出发布正文与准确 hashtags；
- 健康建议是否包含必要的适用边界和停止条件。

采纳后按 `chinese-copy.md` 回归事实与真人感。

### 3. 图片提示词

在生成前逐张确认：

- 该图只承担一个认知任务；
- 人物年龄、身份、服装、视角、动作阶段和情绪明确；
- 器械类型、座椅、护垫、握柄、钢索、滑轮、配重和接触点明确；
- 参考图只约束指定角色，不把旧图缺陷和错误文字一并继承；
- 已写明不要虚影、解剖图、额外人物、额外肢体、品牌、水印和伪字；
- 已列出本页全部逐字中文，禁止额外文字、伪字、第三方品牌和水印。

### 4. 每张成图

必须查看原始项目文件，不只看缩略图。训练图逐格检查：

- 成年自然比例；脊柱、骨盆、肩、肘、腕、髋、膝、踝方向合理；
- 动作处于所写阶段，身体姿态与动作名称一致；
- 双手握住同一正确部件；脚、膝、背、胸和臀没有穿透器械；
- 座椅、护垫、横杆、钢索、滑轮、配重和导轨属于同一台合理器械；
- 单人动作没有变成两人对拉，起止状态没有混在同一静态画面；
- 帽檐不遮眼，服装、人物身份和同组画风一致；
- 没有解剖肌肉高亮、虚影、乱码、可读他牌、广告或水印。
- 人物通过 Softfit 式舒服自洽、舒展体态、健康肌肉线条和坦荡目光呈现本命感、力量感与少女野心，而不是靠潮流广告感、口号、幼态脸或夸张身材；“少女”不得被画成未成年人或幼态长相。

任一关键结构失败，该资产即失败。重做对应图片，不用裁切、遮挡、箭头或文案掩盖。

### 5. 最终排版

- 标题、正文、组次、动作提示和 tags 与当前文案一致；
- 图片顺序、编号和逐页任务一致；
- 文字不拉伸、不截断、不压住脸、手、脚或器械接触点；
- 画布保持原生尺寸，页面边缘完整且没有意外裁切；
- 整组节奏清楚，知识或教程信息在手机画面无需放大；
- 原始文件目视检查通过，且尺寸与资产记录一致。

## 建议与采纳记录

每条问题记录：

- `stage`：发生节点；
- `readerEvidence`：具体句子、页面、图片或接触点；
- `likelyResponse`：目标读者可能的理解或信任问题，注明为模拟判断；
- `recommendation`：最小修改；
- `decision`：`adopt`、`partial` 或 `reject`；
- `rationale`：来源、声音、视觉或平台理由；
- `appliedLocation`：实际修改位置，未采纳为 `null`。

修改后只复核受影响阶段及其下游。任何文字、图片或模板变化都更新 SHA 并使旧批准失效。
